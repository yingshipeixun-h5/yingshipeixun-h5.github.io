// class types

班 型

不同人群，不该坐同一间教室。

零基础就业班 ·全日制

  • 适合：转行 / 应届生
  • 周期：4–6 个月常见
  • 重点：剪辑+调色+包装+作品集
  • 产出：3–5 部商用级成片

周末短视频班 ·在职/在校

  • 适合：副业 / 自媒体
  • 重点：手机拍摄+剪映+账号运营
  • 产出：探店/口播/短剧片段
  • 节奏：不脱产，能落地

线上直播 / 录播班 ·异地

  • 适合：小城市学员
  • 重点：软件工作流+作业点评
  • 优势：可回看、成本低
  • 短板：片场感弱，要自驱

剧组实战班 ·进阶

  • 适合：有基础想入行
  • 重点：分组开机、场记、调度
  • 产出：独立短片/微电影
  • 价值：懂剧组怎么干活

// trainee logs

学员 手记

小白、转行人、在校生，痛点不一样。

🐣 纯小白

先别买相机，先拉 50 部片

很多人一上来问“学 PR 还是剪映”。其实先看懂《肖申克的救赎》《疯狂的石头》《爱乐之城》的镜头为什么这么切，比背按钮重要。小白最值钱的是审美底盘，不是软件速度。

🧳 转行人

别学“全栈影视”，先选一个能吃饭的岗

30 岁转行最怕被机构忽悠“导演剪辑调色特效全教”。真实路径是：剪辑/短视频/宣传片先上岗，再补调色包装，再用作品集跳大厂。转行要的是可交付能力，不是课程表长度。

🎓 在校生

寒暑假别只考证，去剧组当场记

在校生有学校作业，但行业认“真项目”。帮同学拍毕业片、去本地传媒公司做探店、给短剧组做场记/跟焦助理，比一张没含金量的证有用。作品集里有一部真商单，简历就活了。

// q & a

培训 问答

影视培训和前面那些“影视网”有什么区别？

前面 32 站是“看片导航”：蜂鸟、芊芊、金梅、纤纤、影视在线观看都在帮你选片。影视培训是“做片导航”：导演、剪辑、调色、摄影、短视频、AI影视、作品集、接单/就业路径。

学影视后期是不是只要会 PR 和剪映就行？

不够。PR/剪映是入口，行业要的是剪辑节奏、调色审美、声音处理、AE 包装、达芬奇校色、商业成片交付。只学按钮，容易变成“套模板的流水线工位”；学完叙事+审美+工作流，才叫后期创作。[8,11](@ref)

AI 影视是不是把导演剪辑都替代了？

短期替代不了判断力和审美。AI 现在更适合做脚本草稿、分镜草图、素材整理、粗剪辅助、数字人播报；但故事好不好、镜头准不准、成片情绪对不对，还是人说了算。学 AI 影视，是把自己变成“会用新工具的老手”，不是把脑子交出去。[1,12](@ref)
